# 🔐 Generador Automático de Contraseñas Seguras (Python)

Este es un script desarrollado en Python que automatiza la creación de contraseñas robustas y aleatorias, ayudando a mitigar riesgos de seguridad y ataques de fuerza bruta en cuentas de usuario.

### 🚀 Características del Proyecto
* **Personalización:** Permite al usuario definir la longitud exacta de la clave.
* **Robustez:** Combina automáticamente letras mayúsculas, minúsculas, números y caracteres especiales (`!@#$...`).
* **Aleatoriedad Criptográfica:** Utiliza la librería nativa `random` de Python para garantizar que cada combinación sea única.

### 🛠️ Tecnologías Utilizadas
* **Python 3.14** (Entorno IDLE nativo).
* Librerías estándar: `random` y `string` (sin dependencias externas).

### 📈 Habilidades Demostradas
* Manipulación de estructuras de datos (listas y strings).
* Control de flujos y entrada de datos por consola (`input`).
* Lógica aplicada a la ciberseguridad básica.
